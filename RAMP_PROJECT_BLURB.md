# Ramp Applied Scientist Intern Project Blurb

Built a reproducible multiclass classification notebook comparing a multinomial
logistic regression baseline against a NumPy neural network implemented from
scratch. The project includes cross-entropy loss, backpropagation, numerical
gradient checking, dropout regularization, and decision-boundary visualizations.
On the validation set, logistic regression reached 0.696970 accuracy, while the
best neural network configuration with dropout reached 0.757576.
